# QuickList

Aplicação web para gerenciamento de listas de compras, construída com HTML, CSS e JavaScript puro.

## Funcionalidades

- Adicionar itens à lista através de um formulário
- Marcar itens como concluídos com checkbox (texto riscado)
- Remover itens da lista com botão de exclusão
- Notificação toast ao excluir um item, com opção de fechar manualmente
- Layout responsivo para dispositivos móveis

## Tecnologias

- HTML5
- CSS3 (variáveis CSS, Flexbox, media queries)
- JavaScript vanilla (sem frameworks ou dependências)
- Fonte [Inter](https://fonts.google.com/specimen/Inter) e [Sora](https://fonts.google.com/specimen/Sora) via Google Fonts

Basta abrir o arquivo `index.html` em qualquer navegador moderno — nenhuma instalação ou dependência necessária.
